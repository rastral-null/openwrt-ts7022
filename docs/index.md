# OpenWrt для TRANSERV TS-7022

Своя прошивка **OpenWrt (Linux 6.18)** для роутера **TRANSERV TS-7022** (МТС).
В официальном OpenWrt SoC **Realtek RTL8197F** не поддерживается — порт сделан с нуля:
SoC, Ethernet и коммутатор RTL8367RB, Wi-Fi (RTL8197G 2,4 ГГц и RTL8812FE 5 ГГц).

Порт вырос из проекта [openwrt-rx23302](https://github.com/Elengal/openwrt-rx23302)
для аппаратно близкого ELECTRA RX23302; часть документации и процедур унаследована
оттуда. Отличия плат и разметки флеша — в [recovery.md](recovery.md) и README.

## Состояние

- Образ TS-7022 **собран и загружен на железе**: ядро 6.18 стартует, драйвер
  Ethernet и коммутатора RTL8367RB работает (в README — реальный лог загрузки).
- Драйвер Wi-Fi (RTL8192FE, 2,4 и 5 ГГц) собирается и включается модулем
  `rtl8192cd`; отдельно в README его работа на плате не зафиксирована.
- Установка через **веб-панель заводской прошивки не проверялась**.
- Процедуры установки по TFTP/UART и возврата на сток унаследованы от порта RX23302;
  на TS-7022 они отдельно не подтверждены. Считайте их вероятными, но не гарантированными.
- Готовых релизов пока нет: образ собирается локально (см. ниже).

## Установка

- [Без разборки: кнопка Reset + TFTP](install-tftp.md) — унаследованная процедура.
- [Через UART](install-uart.md) — запасной путь, есть отдельный скрипт
  `tools/flash-uart-ts7022.py`.

Перед использованием этих страниц прочитайте предупреждение в начале каждой:
адреса, имена файлов и смещения обновлены под TS-7022, но сама процедура
на TS-7022 пока не проверялась.

## Если что-то пошло не так

- [Восстановление заводской прошивки](recovery.md) — с v0.2 второй банк флеша
  (0x800000) отдан под overlay, поэтому возврат на сток — только через TFTP/UART
  по сохранённому дампу флеша.

## Для разработчиков

- Сборка TS-7022: `./build-ts7022.sh` (по умолчанию в `build-ts7022/`).
  Результат — `openwrt-rtl819x-rtl8197f-transerv_ts7022-squashfs-full.bin`.
- Старый путь сборки RX23302 сохранён: `./build.sh`.
- [Исходники, патчи и сборка](sources.md)
